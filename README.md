# Sales Data Analysis Using SQL & Power BI

## Project Overview
An end-to-end sales data analysis project using MySQL and Power BI to explore sales performance, customer activity, product revenue, and order trends.

This project demonstrates SQL querying, data analysis, business insights, and interactive dashboard development.

## Dashboard Preview

![Sales Dashboard](sales_analysis%20dashboard.png)

## Tools & Technologies
- **Database:** MySQL
- **SQL Environment:** MySQL Workbench
- **Data Visualization:** Power BI Desktop
- **Query Language:** SQL
- **Calculations:** DAX

## Dashboard Features
- Monthly Order Trend
- Monthly Revenue Trend
- Order Status Distribution
- Top 5 Products by Revenue
- Revenue by City
- Interactive filters for order status and city

## SQL Analysis
SQL queries were used to explore sales records, analyze orders, calculate revenue, and examine customer and product performance.

## Data Quality Observation
The database contains 30 orders, but order-detail records are available for only 5 orders.

Therefore, ₹425,000 represents revenue calculated from the available order details. Revenue for the remaining orders is unknown and is not included in this figure.
